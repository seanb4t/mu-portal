# Contributing to mu-portal

Thank you for your interest in mu-portal. This file is a pointer. The Contributing pages of the documentation site hold the rules.

## First step

Install [`mise`](https://mise.jdx.dev). Then run these commands in the root of the repository:

```sh
mise install
mise run check
```

`mise install` gets every tool of the project. `mise run check` runs every check of the Rust workspace.
