# mu-portal

mu-portal is a client and server for MU* text games: MUSH, MUX, AresMUSH and Evennia games. One program, `mu`, carries every function as a verb.

## Status

The project is at its foundation. The `mu` binary builds and has three verbs. The `client` verb and the `server` verb report that they are not implemented.
