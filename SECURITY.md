# Security policy

## How to report a vulnerability

Report a vulnerability in private. Do not open a public issue for it.

1. Open the [Security tab](https://github.com/seanb4t/mu-portal/security) of the repository.
2. Select "Report a vulnerability".
3. Describe the problem, the affected version and the steps that show it.

GitHub sends the report to the maintainer only.

## What to expect

The maintainer reads each report and answers in the same private thread. After a fix is released, the maintainer publishes an advisory and credits the reporter, unless the reporter asks for no credit.

## Supported versions

The project has no release yet. Until the first release, only the `main` branch receives fixes.
