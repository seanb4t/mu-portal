The workspace has six crates. `mu-tui` does not depend on `mu-core` or `mu-server`, so the terminal client cannot reach the server engine except through the API. `mu-core` does not depend on `mu-proto`, so the engine does not know the wire format.

This view is a copy of the allowlist in `crates/mu-cli/tests/workspace_boundary.rs`. The test is the source of the rule. The [workspace layout](/contributing/workspace/) page explains how to change both.
