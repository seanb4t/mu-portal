## Decision

The project uses the Apache-2.0 license. Every crate states that license. A test fails for a crate that does not.

## Reason

Apache-2.0 allows wide use and includes a patent grant. The project cannot copy code from a client under the GPL, for example Blightmud. The project can read such code to learn how a protocol behaves.

## Source

The first exploration. The OpenSpec change `project-foundation` replaced the MIT license of the first commit.
