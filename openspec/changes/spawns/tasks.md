# Tasks: spawns

Test files: `crates/mu-core/tests/rules.rs` (new) holds the unit tests of `Rules` and `RuleState`. `crates/mu-core/tests/scripts.rs` holds the test of the hook seam. `crates/mu-config/tests/stream.rs` (new) holds the tests of `StreamName`, `Streams` and `Selection`. `crates/mu-config/tests/ansi.rs` (new) holds the tests of the walk of game text. `crates/mu-config/tests/layout.rs` holds the tests of the grammar and the checks. `crates/mu-cli/tests/world_config.rs` holds the tests of `mu world list`, `mu world show` and `mu world match`. `crates/mu-cli/tests/journal.rs` holds the tests of the server with a fake world. `crates/mu-cli/tests/layout.rs` holds the tests of `mu layout show`. `crates/mu-tui/tests/update.rs` and `crates/mu-tui/tests/app.rs` hold the unit tests of the client. `crates/mu-cli/tests/client.rs` holds the tests of `mu client`. The one-test command is in `openspec/config.yaml`.

Each group lands its own tests and documentation before the next group starts.
